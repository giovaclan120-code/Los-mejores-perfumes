# The World of Perfumes

Revista digital de perfumería creada con React + Vite.

## Ejecutar localmente
1. Instala Node.js (versión 18 o superior).
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre la dirección local que muestra Vite.

## Publicar en Render
1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En Render, crea un servicio **Static Site** y conecta el repositorio.
3. Build Command: `npm install && npm run build`
4. Publish Directory: `dist`
5. Puedes usar también el archivo `render.yaml` incluido.

Las imágenes se cargan desde Unsplash mediante URLs remotas, por lo que se necesita conexión a Internet para verlas.
